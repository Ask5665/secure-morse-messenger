How It Works

Encrypt

Each letter moves 3 places forward (A→D, H→K), then every character becomes dots and dashes. Words are separated by /.

HELLO → KHOOR → -.- .... --- --- .-.

Decrypt

Morse code is decoded back to letters, then each letter moves 3 places backward (K→H).

-.- .... --- --- .-. → KHOOR → HELLO

Digits are encoded in Morse as they are; the Caesar shift only changes letters. Decryption returns uppercase text.

Security Information

Caesar +3 is a classical educational cipher and is not considered secure modern encryption. Morse code is an encoding method, not encryption.

This project demonstrates encryption concepts, decryption, encoding, decoding, classical cryptography and Morse communication. Do not use it to protect sensitive information.
